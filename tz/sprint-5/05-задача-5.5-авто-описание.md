## 🎯 Цель

Сценарий агента: для задачи с пустым/коротким описанием сгенерировать черновик структурированного описания на основе заголовка и контекста проекта. Как предложение, не перезапись.

## 📋 Контекст для Claude Code

Действие `update_description` из белого списка 5.2, но описание — пользовательский контент, перезаписывать молча нельзя. Агент добавляет черновик в выделенном виде (например, в комментарий или в описание с пометкой «черновик ИИ, отредактируйте»), чтобы человек принял/поправил.

## ✅ Что сделать

1. Триггер: задача создана с заголовком, но пустым/очень коротким описанием.
2. Промпт: на вход заголовок + контекст проекта (похожие задачи через RAG), на выход — структурированный черновик (контекст, шаги, критерии готовности — по шаблону команды).
3. Запись: добавить черновик с явной пометкой «🤖 Черновик описания, отредактируйте» — НЕ затирать существующий контент.
4. Не запускать, если описание уже содержательное.
5. Аудит.

## ✅ Definition of Done

- [ ] Задачи с пустым описанием получают черновик
- [ ] Черновик помечен как сгенерированный, существующий контент не затирается
- [ ] Не срабатывает на задачах с уже содержательным описанием
- [ ] Используется контекст проекта (RAG)
- [ ] Все действия в аудит-логе
- [ ] Тест: пустое описание → черновик; заполненное → пропуск

## ⚠️ Важно

Описание — пользовательский контент. Никогда не затирать существующее молча. Черновик добавляется явно помеченным, человек решает оставить/изменить.
