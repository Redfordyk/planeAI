## 🎯 Цель

Интерфейс прозрачности агента: лента всех его действий с возможностью отмены/отката, чтобы команда видела и контролировала, что агент сделал автономно.

## 📋 Контекст для Claude Code

Агент действует без человека в каждом шаге — поэтому критична видимость постфактум. Аудит-лог пишется воркером (5.2). UI показывает: что агент сделал, на какой задаче, когда, на основании чего. Плюс возможность отменить обратимое действие.

## ✅ Что сделать

1. Эндпоинт чтения аудит-лога агента (с правами: видит только свой воркспейс/проекты).
2. UI-лента: список действий агента (задача, действие, время, обоснование), фильтры по проекту/типу.
3. Кнопка «Отменить» для обратимых действий (снять метку, вернуть приоритет) — где это технически возможно.
4. Индикатор активности агента (включён/выключен), переключатель enable/disable агента (только админ).
5. Бейдж «🤖 действие ИИ» на задачах, которые трогал агент.

## ✅ Definition of Done

- [ ] Лента действий агента отображается, с фильтрами
- [ ] Каждое действие: задача, тип, время, обоснование
- [ ] Отмена обратимых действий работает
- [ ] Переключатель агента (enable/disable) для админа
- [ ] Действия агента визуально помечены на задачах
- [ ] Права: пользователь видит только свои проекты
- [ ] Стиль консистентен с Plane

## ⚠️ Важно

Прозрачность — главный механизм доверия к автономному агенту. Если команда не видит, что агент делает, они его выключат. Лента действий — не «приятно иметь», а условие принятия фичи.
