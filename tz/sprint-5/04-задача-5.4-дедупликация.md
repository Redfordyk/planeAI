## 🎯 Цель

Сценарий агента: при создании задачи найти похожие через RAG и предложить их объединить (не объединять автоматически — слияние необратимо). Снижает дубли в бэклоге.

## 📋 Контекст для Claude Code

RAG (2.1) уже умеет находить семантически близкие чанки. Дедупликация = поиск похожих задач + предложение мержа. Слияние/закрытие задачи — необратимо, поэтому агент только ПРЕДЛАГАЕТ (комментарий со ссылками на дубли), решение за человеком.

## ✅ Что сделать

1. При создании задачи — retrieve похожих в пределах проекта (порог косинусной близости настраиваемый).
2. Если найдены кандидаты выше порога:
   - добавить комментарий «Возможные дубли: [ссылки на задачи]» (действие из белого списка — `add_comment`, добавить если нужно)
   - навесить метку `possible-duplicate`
3. НЕ закрывать, НЕ мержить автоматически.
4. Порог похожести настраиваемый (чтобы не спамить ложными срабатываниями).
5. Аудит.

## ✅ Definition of Done

- [ ] Похожие задачи находятся через RAG в пределах проекта
- [ ] При превышении порога — комментарий со ссылками + метка
- [ ] Слияние/закрытие НЕ выполняется автоматически
- [ ] Порог настраиваемый, ложные срабатывания минимизированы
- [ ] Все действия в аудит-логе
- [ ] Тест: дубль детектится, оригинал — нет; ничего не закрывается автоматически

## ⚠️ Важно

Слияние задач необратимо → агент только предлагает. Автоматическое закрытие «дубля» при ложном срабатывании = потеря задачи. Человек в контуре обязателен для необратимого.
