## 🎯 Цель

DRF-эндпоинты для трёх операций генерации: саммари страницы, статус-отчёт по задаче/набору, организация заметок. С проверкой прав, учётом токенов, опционально стримингом. Большие артефакты (отчёты) — в S3/MinIO Plane.

## 📋 Контекст для Claude Code

Используй промпты 3.1, Claude из 1.3 (модель Haiku для саммари — дёшево), `record_usage` (1.7), `@require_ai_budget` (1.7). Проверка прав на объект — через ACL (0.6). Plane уже даёт S3-совместимое хранилище для AI-артефактов.

## ✅ Что сделать

```python
# ai/views.py (дополнение)
@api_view(["POST"])
@require_ai_budget
def summarize_page(request, workspace_id, page_id):
    page = get_object_or_404(Page, id=page_id)
    check_project_access(request.user, page.project_id)   # ACL обязательно
    cfg = request.ai_cfg
    client = anthropic.Anthropic(api_key=cfg.anthropic_key)
    resp = client.messages.create(
        model="claude-haiku-4-5-20251001", max_tokens=800,
        system=[{"type":"text","text":SUMMARIZE_PAGE,"cache_control":{"type":"ephemeral"}}],
        messages=[{"role":"user","content":page.description_stripped}],  # контент в user!
        temperature=0.1)
    record_usage(workspace_id, request.user.id, "summarize",
                 "claude-haiku-4-5-20251001", resp.usage)
    return Response({"summary": resp.content[0].text})
```

Аналогично:
- `status_report` — собирает комментарии/обновления задачи, прогоняет через STATUS_REPORT
- `organize_notes` — принимает текст, возвращает структурированный

Доп:
- Большой результат (отчёт) можно сохранять в S3 и возвращать ссылку (см. как Plane грузит файлы — ONBOARDING.md).
- Опционально стриминг (переиспользовать 2.3) для длинных генераций.
- Поля контента (`description_stripped` и т.п.) — из SCHEMA.md.
