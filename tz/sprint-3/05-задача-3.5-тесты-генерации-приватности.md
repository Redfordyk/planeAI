## ✅ Что сделать

1. **Генерация (юнит, мок Claude):**
   - `test_summarize_requires_access`: без прав на проект → 403
   - `test_summarize_records_usage`: вызов пишет AIUsageLog
   - `test_content_in_user_role`: контент объекта идёт в user-сообщение, не в system (проверить структуру вызова Claude)
2. **Приватность (юнит):**
   - `test_excluded_project_not_indexed`: проект с `exclude_from_ai=True` → новый объект не индексируется (через сигнал 1.4)
   - `test_excluded_project_not_in_search`: чанки исключённого проекта не возвращаются retrieve (2.1)
   - `test_enabling_exclusion_deletes_chunks`: включение флага удаляет существующие чанки проекта (3.4)
3. **Инъекции в генерации (integration, маркер):**
   - страница с инъекцией внутри → саммари не выполняет инъекцию

```python
@pytest.mark.django_db
def test_enabling_exclusion_deletes_chunks(make_workspace, make_project, make_chunk):
    ws = make_workspace("A"); p = make_project(ws)
    make_chunk(workspace=ws, content="task", project=p)
    assert DocumentChunk.objects.filter(project=p).count() == 1
    # PUT exclude_from_ai=True
    set_exclude(p, True)
    assert DocumentChunk.objects.filter(project=p).count() == 0
```
