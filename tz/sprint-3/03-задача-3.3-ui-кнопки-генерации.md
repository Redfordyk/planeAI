## 🎯 Цель

Добавить в интерфейс Plane кнопки вызова генерации: «Суммировать» на странице, «Статус-отчёт» на задаче, «Организовать заметки» в редакторе. Результат показывается inline с возможностью вставить/скопировать.

## 📋 Контекст для Claude Code

Фронт Plane — Next.js (`apps/web`). Эндпоинты — из 3.2. Где саммари длинные — переиспользовать SSE-логику из useAISearch (2.4) для стриминга. Кнопки встраиваются в существующие элементы Plane (страница, карточка задачи), минимально вторгаясь в их код.

## ✅ Что сделать

1. Кнопка «Суммировать» на странице (Page) → вызов `summarize_page` → показать саммари в панели/модалке, кнопки «Скопировать» / «Вставить в страницу».
2. Кнопка «Статус-отчёт» на задаче → `status_report`.
3. Действие «Организовать» в редакторе заметок → `organize_notes`, с превью до применения.
4. Состояния: loading (спиннер/стриминг), error (бюджет/права/провайдер), success.
5. Индикация расхода (опционально): «использовано N токенов».

## ✅ Definition of Done

- [ ] Три действия доступны в соответствующих местах UI
- [ ] Результат показывается, есть «Скопировать»/«Вставить»
- [ ] Состояния loading/error/success обработаны
- [ ] Ошибки 429/403 показываются понятно
- [ ] Стиль консистентен с Plane
- [ ] Длинные генерации стримятся (не висит спиннер)

## ⚠️ Важно

«Организовать заметки» меняет пользовательский текст — обязательно показывай превью ДО применения, не перезаписывай молча. Пользователь должен подтвердить.
