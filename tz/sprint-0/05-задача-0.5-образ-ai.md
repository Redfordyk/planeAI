## 🎯 Цель

Решить и реализовать, **как наше Django-приложение `ai` попадает в работающий Plane**. Plane поставляется готовым образом `makeplane/plane-backend` — просто положить файлы нельзя, они исчезнут при перезапуске. Нужен воспроизводимый способ.

## 📋 Контекст для Claude Code

Backend Plane = образ `makeplane/plane-backend`, исходники в репо `apps/api`. Два пути:
- **Хак (прототип):** bind-mount папки `ai/` в контейнеры `api` и `worker` + регистрация в `INSTALLED_APPS`. Быстро, но грязно и нестабильно при апгрейдах.
- **Правильный:** свой образ `FROM makeplane/plane-backend`, копирующий `ai/` и доставляющий зависимости (pgvector, openai, anthropic, tiktoken). Это и пойдёт в CI/CD (0.9).

Берём **правильный путь** — он нужен для CI/CD и прода.

## ✅ Что сделать

1. Создать `Dockerfile.ai`:
   ```dockerfile
   FROM makeplane/plane-backend:<зафиксированная-версия-из-0.1>
   COPY ai/ /code/ai/      # путь /code подтвердить из 0.1 (docker compose exec api pwd)
   RUN pip install --no-cache-dir pgvector openai anthropic tiktoken \
       django-encrypted-model-fields
   ```
2. Решить регистрацию `ai` в `INSTALLED_APPS`. Так как settings внутри образа — выбрать механизм:
   - либо патч settings через `local_settings`/override, если Plane его поддерживает,
   - либо переменная окружения + динамическое добавление,
   - либо наследование settings. **Зафиксировать выбор в IMAGE.md.**
3. Создать `docker-compose.override.yml`, заменяющий образ `api`/`worker`/`beat-worker` на собранный `plane-backend-ai`.
4. Собрать, поднять, убедиться что Plane по-прежнему работает И приложение `ai` видно Django (`python manage.py showmigrations ai`).

## 📦 Артефакты

- `Dockerfile.ai`
- `docker-compose.override.yml` (подмена образа backend-сервисов)
- `IMAGE.md`: как `ai` регистрируется в INSTALLED_APPS, как собирать образ

## ✅ Definition of Done

- [ ] `docker build -f Dockerfile.ai` собирается без ошибок
- [ ] После запуска Plane работает как раньше (регресс не сломан)
- [ ] `python manage.py showmigrations ai` показывает приложение `ai`
- [ ] Зафиксирован способ регистрации в INSTALLED_APPS
- [ ] Все три backend-сервиса (api, worker, beat-worker) используют новый образ
- [ ] IMAGE.md закоммичен

## ⚠️ Важно

- Версию базового образа **фиксируй явно** (не `:latest`) — иначе апгрейд Plane молча сломает сборку.
- `api`, `worker` и `beat-worker` должны использовать ОДИН образ — иначе хуки/задачи `ai` будут видны не везде.
