## 🎯 Цель

Настроить в самом Plane проект для управления этой разработкой: импортировать backlog (49 задач из `backlog.xlsx`), создать эпики по спринтам, циклы (sprints), назначить исполнителей. «Едим свою еду» — управляем разработкой ИИ-надстройки в том же Plane.

## 📋 Контекст (организационная задача, не код)

Plane поддерживает: work items (задачи), epics (эпики), cycles (циклы = спринты), modules, labels, multiple views (Kanban/list). Backlog уже готов в Excel — нужно перенести.

## ✅ Что сделать

1. Создать проект «AI Layer for Plane» в тестовом воркспейсе.
2. Создать 7 эпиков = 7 спринтов (Спринт 0…6).
3. Создать 7 циклов с датами из backlog (22.05–09.07).
4. Импортировать 49 задач: можно через CSV-импорт Plane или вручную. Поля: название, исполнитель, цикл, эпик, метки.
5. Настроить метки: по фазам (RAG, поиск, генерация, bulk, агенты, инфра), по типу (backend, frontend, qa, infra, legal).
6. Создать связи блокировки между задачами (из колонки «Связано с»).
7. Настроить Kanban-доску со статусами: Backlog / In Progress / Review / Done / Blocked.
