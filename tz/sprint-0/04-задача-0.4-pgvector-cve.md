## 🎯 Цель

Убедиться, что в Postgres Plane доступно расширение **pgvector версии ≥ 0.8.2**, и установить/обновить его. Версии 0.7.x / 0.8.0 / 0.8.1 содержат критическую уязвимость **CVE-2026-3172** (CVSS 8.1, buffer overflow при параллельной сборке HNSW-индекса, может утечь данные из несвязанных таблиц или уронить сервер).

## 📋 Контекст для Claude Code

Мы будем хранить векторы (эмбеддинги задач) в той же Postgres, что использует Plane, через расширение pgvector с HNSW-индексом. Сборка HNSW — именно тот код, где срабатывает CVE. Поэтому версия критична до создания индекса в задаче 1.2.

## ✅ Что сделать

1. Проверить текущую версию (если расширение вообще установлено):
   ```bash
   docker compose exec plane-db psql -U plane -d plane -c \
     "SELECT extversion FROM pg_extension WHERE extname='vector';"
   ```
2. Проверить, какая версия pgvector доступна в образе Postgres:
   ```bash
   docker compose exec plane-db psql -U plane -d plane -c \
     "SELECT * FROM pg_available_extension_versions WHERE name='vector';"
   ```
3. Если образ Postgres не содержит pgvector ≥0.8.2 — заменить образ на `pgvector/pgvector:pg16` (или совместимый с версией PG в Plane) актуальной версии, либо собрать кастомный образ. **Зафиксировать выбор в PGVECTOR.md.**
4. Если апгрейд невозможен прямо сейчас — задокументировать временный workaround: отключить параллельные maintenance-воркеры (`SET max_parallel_maintenance_workers = 0;`). На малом объёме это не больно.

## 🔍 Команды проверки
