## 🎯 Цель

Написать скрипт, который **печатает реальные имена Django-моделей и полей** Plane, чтобы заменить все наши предположения (`Issue`, `ProjectMember`, `Page`, app `db`...) на проверенные факты. Без этого код спринта 1 стоит на догадках и не запустится.

## 📋 Контекст для Claude Code

В общем контексте перечислены неверифицированные допущения. Backend Plane — Django, модели лежат в одном из приложений (предположительно `db`). Нам нужно точно знать: как называется модель задачи, комментария, страницы, проекта, воркспейса, членства в проекте; в каком app они зарегистрированы; какие у них ключевые поля (FK на workspace/project, текстовые поля с контентом).

## ✅ Что сделать

1. Написать management-команду `verify_schema`, которая через Django introspection выводит:
   - список всех установленных app и их моделей,
   - для кандидатов (задача, комментарий, страница, проект, воркспейс, членство) — точное имя модели, app_label, и поля с типами,
   - какие поля являются FK на Workspace / Project,
   - какие текстовые поля содержат пользовательский контент (`name`, `description`, `description_html`, `description_stripped` и т.п.).
2. Запустить внутри `api`-контейнера.
3. Оформить результат в `SCHEMA.md` — таблицу соответствия «наше предположение → реальное имя».

## 💻 Опорный код (доработать через Claude Code)

```python
# verify_schema.py — management command
from django.apps import apps

def handle(self, *args, **opts):
    keywords = ["issue", "work", "comment", "page", "project", "workspace", "member"]
    for model in apps.get_models():
        name = model.__name__.lower()
        if any(k in name for k in keywords):
            print(f"\n=== {model._meta.app_label}.{model.__name__} ===")
            for f in model._meta.get_fields():
                ftype = f.get_internal_type() if hasattr(f, "get_internal_type") else type(f).__name__
                rel = getattr(f, "related_model", None)
                print(f"  {f.name}: {ftype}" + (f" -> {rel.__name__}" if rel else ""))
```

Запуск:
```bash
docker compose exec api python manage.py verify_schema > schema_dump.txt
```

## 📦 Артефакты
