## 🎯 Цель

UI-дашборд расхода: сколько токенов и денег потрачено за месяц, в разбивке по фичам (поиск/саммари/bulk/агент/эмбеддинги) и по пользователям. Чтобы команда видела стоимость и управляла бюджетом.

## 📋 Контекст для Claude Code

Данные — в `AIUsageLog` (1.7): feature, model, токены, cost_usd, дата. Нужен эндпоинт агрегации + визуализация. Помогает понять, какая фича сколько стоит, и не упереться в бюджет внезапно.

## ✅ Что сделать

1. Бэкенд-эндпоинт агрегации: расход за период с группировкой по feature / model / user (с правами: админ воркспейса).
2. UI-дашборд:
   -总 расход за месяц ($ и токены) против лимита (прогресс-бар)
   - разбивка по фичам (диаграмма)
   - топ пользователей по расходу
   - тренд по дням
3. Фильтры: период, воркспейс.

## ✅ Definition of Done

- [ ] Эндпоинт агрегации по feature/model/user
- [ ] Дашборд: общий расход vs лимит, разбивка по фичам, тренд
- [ ] Права: только админ воркспейса видит расход
- [ ] Цифры сходятся с AIUsageLog
- [ ] Стиль консистентен с Plane

## ⚠️ Важно

Дашборд читает AIUsageLog — убедись, что все фичи (1.5 embed, 2.3 search, 3.2 generation, 4.2 bulk, 5.2 agent) реально пишут usage с правильным `feature`. Если какая-то фича не логируется — дашборд врёт в меньшую сторону, и бюджет уйдёт незаметно.
