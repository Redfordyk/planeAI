## 🎯 Цель

Определить набор инструментов (tool-use схем Anthropic), которыми Claude оперирует для bulk-операций: поиск задач по фильтрам (read) и массовое обновление (write). Это контракт между моделью и нашим кодом.

## 📋 Контекст для Claude Code

Принцип №2 из контекста: LLM ВЫБИРАЕТ инструмент и параметры, ВЫПОЛНЯЕТ наш код после ACL. Read-инструменты выполняются сразу, write — только после подтверждения (4.3). Поля задач (cycle, state, assignee) и их значения — из SCHEMA.md (0.2).

## ✅ Что сделать

```python
# ai/tools.py
TOOLS = [
    {
        "name": "find_work_items",
        "description": "Найти задачи по фильтрам (цикл, статус, исполнитель, метки).",
        "input_schema": {
            "type": "object",
            "properties": {
                "cycle_id":    {"type": "string"},
                "state_group": {"type": "string",
                    "enum": ["backlog","unstarted","started","completed","cancelled"]},
                "assignee_id": {"type": "string"},
                "label_ids":   {"type": "array", "items": {"type": "string"}},
            },
        },
    },
    {
        "name": "bulk_update_work_items",
        "description": "Массово обновить поля у задач по списку ID.",
        "input_schema": {
            "type": "object",
            "properties": {
                "work_item_ids": {"type": "array", "items": {"type": "string"}},
                "set_cycle_id":  {"type": "string"},
                "set_state_id":  {"type": "string"},
                "set_assignee_id":{"type": "string"},
            },
            "required": ["work_item_ids"],
        },
    },
]
```

Доп:
- `exec_find(input, workspace_id, project_id, user)` — реальный поиск через ORM с ACL-фильтром (allowed_projects).
- Значения `state_group` свериться с реальными статусами Plane (SCHEMA.md).
- НЕ добавлять деструктивные инструменты (delete) — запрещено принципами.

## ✅ Definition of Done

- [ ] Tool-схемы определены, валидны для Anthropic tool-use
- [ ] `state_group` соответствует реальным статусам Plane (SCHEMA.md)
- [ ] `exec_find` выполняет поиск с ACL-фильтром по правам пользователя
- [ ] Нет деструктивных инструментов (delete/удаление)
- [ ] Юнит-тест: exec_find не возвращает задачи вне прав пользователя

## ⚠️ Важно

Никаких delete-инструментов — удаление в списке запрещённых действий. Bulk = изменение полей, не уничтожение.
