## 🎯 Цель

Цикл обработки команды: Claude получает инструкцию на естественном языке, выбирает инструменты, read-инструменты выполняются и возвращаются модели, цикл повторяется до финального ответа или write-операции. С защитой от зацикливания.

## 📋 Контекст для Claude Code

Anthropic tool-use: ответ модели содержит блоки `tool_use`; мы выполняем read-инструменты, возвращаем `tool_result`, модель продолжает. Write-инструмент (bulk_update) НЕ выполняется здесь — возвращается на подтверждение (4.3). Лимит шагов обязателен — иначе модель может зациклиться и сжечь бюджет.

## ✅ Что сделать

```python
# ai/agent.py
import json
from ai.providers import ClaudeChat
from ai.tools import TOOLS, exec_find
from ai.usage import record_usage

MAX_STEPS = 6

def run_command(ws_id, project_id, user, instruction, cfg):
    chat = ClaudeChat(cfg.anthropic_key)
    messages = [{"role": "user", "content": instruction}]

    for _ in range(MAX_STEPS):
        resp = chat.complete(system="Ты помощник по управлению задачами.",
                             messages=messages, tools=TOOLS)
        record_usage(ws_id, user.id, "bulk", cfg.chat_model, resp.usage)

        tool_uses = [b for b in resp.content if b.type == "tool_use"]
        if not tool_uses:
            text = "".join(b.text for b in resp.content if b.type == "text")
            return {"type": "answer", "text": text}

        messages.append({"role": "assistant", "content": resp.content})
        results = []
        for tu in tool_uses:
            if tu.name == "find_work_items":                 # READ — выполняем
                data = exec_find(tu.input, ws_id, project_id, user)
                results.append({"type":"tool_result","tool_use_id":tu.id,
                                "content": json.dumps(data)})
            elif tu.name == "bulk_update_work_items":        # WRITE — на подтверждение
                return _prepare_confirmation(tu, user)        # см. 4.3
        messages.append({"role": "user", "content": results})

    return {"type": "answer", "text": "Превышен лимит шагов обработки команды."}
```

## ✅ Definition of Done

- [ ] Read-инструменты выполняются и возвращаются модели, цикл продолжается
- [ ] Write-инструмент НЕ выполняется в цикле, уходит на подтверждение (4.3)
- [ ] Лимит `MAX_STEPS` предотвращает зацикливание
- [ ] Каждый шаг пишет расход в AIUsageLog
- [ ] Финальный текстовый ответ возвращается корректно
- [ ] Тест: цикл с read-инструментом завершается ответом; цикл с write — уходит на confirm

## ⚠️ Важно

- Лимит шагов — защита бюджета. Без него прокликивание инструментов может уйти в бесконечность.
- Write НИКОГДА не выполняется внутри loop — только подготовка к подтверждению.
