## 🎯 Цель

Единый учёт расхода токенов и денег по каждому LLM-вызову + защитный guard, отклоняющий ИИ-запросы (429) при превышении месячного бюджета воркспейса. Чтобы зациклившийся агент не сжёг счёт у Anthropic.

## 📋 Контекст для Claude Code

Структура usage в Anthropic SDK: `input_tokens`, `output_tokens`, `cache_read_input_tokens`, `cache_creation_input_tokens`. Cache-read токены биллятся по 10% базовой цены. Эмбеддинги — только input. Бюджет хранится в `WorkspaceAIConfig.monthly_token_budget`.

## ✅ Что сделать

```python
# ai/usage.py
from decimal import Decimal
from django.db.models import Sum
from django.utils import timezone

PRICING = {  # $ за токен (цена за Mtok / 1e6) — проверять против офиц. прайса
    "claude-sonnet-4-6":         {"in": Decimal("0.000003"),  "out": Decimal("0.000015")},
    "claude-haiku-4-5-20251001": {"in": Decimal("0.0000008"), "out": Decimal("0.000004")},
    "text-embedding-3-small":    {"in": Decimal("0.00000002"), "out": Decimal("0")},
}

def _cost(model, u):
    p = PRICING.get(model)
    if not p: return Decimal("0")
    cache_read = getattr(u, "cache_read_input_tokens", 0) or 0
    return (u.input_tokens * p["in"]
            + cache_read * p["in"] * Decimal("0.10")
            + u.output_tokens * p["out"])

def record_usage(workspace_id, user_id, feature, model, usage):
    cost = _cost(model, usage)
    AIUsageLog.objects.create(
        workspace_id=workspace_id, user_id=user_id, feature=feature, model=model,
        input_tokens=usage.input_tokens, output_tokens=usage.output_tokens,
        cache_read_tokens=getattr(usage,"cache_read_input_tokens",0) or 0,
        cache_creation_tokens=getattr(usage,"cache_creation_input_tokens",0) or 0,
        cost_usd=cost)
    return cost

def tokens_used_this_month(workspace_id) -> int:
    start = timezone.now().replace(day=1, hour=0, minute=0, second=0, microsecond=0)
    a = AIUsageLog.objects.filter(workspace_id=workspace_id, created_at__gte=start)\
        .aggregate(s=Sum("input_tokens"), o=Sum("output_tokens"))
    return (a["s"] or 0) + (a["o"] or 0)

# ai/guards.py — декоратор для DRF-вьюх
from functools import wraps
from rest_framework.response import Response

def require_ai_budget(view):
    @wraps(view)
    def wrapper(self, request, *args, **kwargs):
        ws = kwargs.get("workspace_id") or request.data.get("workspace_id")
        cfg = WorkspaceAIConfig.objects.filter(workspace_id=ws, enabled=True).first()
        if not cfg:
            return Response({"error":"AI disabled"}, status=403)
        if tokens_used_this_month(ws) >= cfg.monthly_token_budget:
            return Response({"error":"Monthly AI budget exceeded",
                             "budget":cfg.monthly_token_budget}, status=429)
        request.ai_cfg = cfg
        return view(self, request, *args, **kwargs)
    return wrapper
```

## ✅ Definition of Done

- [ ] `record_usage` пишет все 4 типа токенов + стоимость, учитывает cache-read по 10%
- [ ] `tokens_used_this_month` корректно суммирует с начала месяца
- [ ] `require_ai_budget`: 403 если ИИ выключен, 429 если бюджет превышен, иначе прокидывает `request.ai_cfg`
- [ ] `PRICING` — единый источник цен (используется и в 1.5)
- [ ] Тесты: подсчёт стоимости, срабатывание 429 на превышении

## ⚠️ Важно

- `record_usage` делает ORM-запись — в async-стриминге (2.3 при ASGI) вызывать через `sync_to_async`, не напрямую из генератора.
- Цены в PRICING проверь против актуального прайса Anthropic/OpenAI на момент внедрения.
