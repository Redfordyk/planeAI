## 🎯 Цель

Слой доступа к LLM: чат через Claude, эмбеддинги через OpenAI, с устойчивостью к rate-limit (429) на ОБА провайдера. Весь код выше работает только с этим слоем, не зная деталей SDK.

## 📋 Контекст для Claude Code

Модели (из контекста): чат `claude-sonnet-4-6` (дешёвые операции — `claude-haiku-4-5-20251001`), эмбеддинги `text-embedding-3-small` (1536). Claude эмбеддинги НЕ отдаёт — поэтому два разных провайдера. Ключи берутся из `WorkspaceAIConfig` (зашифрованы). У обоих SDK есть встроенный retry, но нам нужен контролируемый backoff с джиттером для логирования.

## ✅ Что сделать

```python
# ai/providers.py
import time, random, anthropic
from openai import OpenAI, RateLimitError, APIError

CHAT_MODEL  = "claude-sonnet-4-6"
CHEAP_MODEL = "claude-haiku-4-5-20251001"
EMBED_BATCH, MAX_RETRIES = 100, 5

class ClaudeChat:
    def __init__(self, api_key):
        self.client = anthropic.Anthropic(api_key=api_key)
    def complete(self, system, messages, tools=None, model=CHAT_MODEL, max_tokens=2048):
        return self.client.messages.create(
            model=model, max_tokens=max_tokens, system=system,
            messages=messages, tools=tools or [], temperature=0.1)

class OpenAIEmbed:
    def __init__(self, api_key, model="text-embedding-3-small"):
        self.client = OpenAI(api_key=api_key, max_retries=0)  # ретраим сами
        self.model = model
    def embed(self, texts) -> tuple[list[list[float]], int]:
        vecs, total = [], 0
        for i in range(0, len(texts), EMBED_BATCH):
            batch = texts[i:i+EMBED_BATCH]
            for attempt in range(MAX_RETRIES):
                try:
                    r = self.client.embeddings.create(model=self.model, input=batch)
                    vecs += [d.embedding for d in r.data]; total += r.usage.total_tokens
                    break
                except RateLimitError:
                    if attempt == MAX_RETRIES-1: raise
                    time.sleep(2**attempt + random.uniform(0,1))
                except APIError:
                    if attempt == MAX_RETRIES-1: raise
                    time.sleep(2**attempt)
        return vecs, total

def get_config(workspace_id):
    return WorkspaceAIConfig.objects.get(workspace_id=workspace_id, enabled=True)
```

Доп. требования:
- На стороне Claude — тоже обработать `anthropic.RateLimitError`/`APIError` (для синхронных вызовов), хотя бы через `max_retries` конструктора + лог.
- Хелпер `get_chat(workspace_id)` / `get_embed(workspace_id)`, читающий ключи из конфига.
- НЕ логировать ключи и тела запросов с пользовательским контентом (см. 0.11).
