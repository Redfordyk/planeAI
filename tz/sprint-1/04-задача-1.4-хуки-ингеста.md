## 🎯 Цель

Подключить сигналы Django, которые при создании/изменении задачи, комментария или страницы ставят задачу переиндексации в очередь Celery. С тремя защитами: только после коммита транзакции, с дебаунсом против дублей, с исключением приватных проектов.

## 📋 Контекст для Claude Code

Имена моделей (`Issue`, `Comment`/`IssueComment`, `Page`) и их app — из SCHEMA.md (0.2). Три тонких бага, которые ОБЯЗАТЕЛЬНО предотвратить:
1. `post_save` стреляет ДО коммита → воркер прочитает старые данные. Решение: `transaction.on_commit`.
2. Частые правки → дубли задач в очереди → лишние токены. Решение: Redis-дебаунс.
3. Приватные проекты (`AIProjectSettings.exclude_from_ai`) не должны уходить в облако.

## ✅ Что сделать

```python
# ai/signals.py
from django.db.models.signals import post_save, post_delete
from django.dispatch import receiver
from django.db import transaction
from django.core.cache import cache
from <app>.models import Issue, IssueComment, Page   # из SCHEMA.md

def _ai_enabled(workspace_id) -> bool:
    return WorkspaceAIConfig.objects.filter(workspace_id=workspace_id, enabled=True).exists()

def _excluded(project_id) -> bool:
    return AIProjectSettings.objects.filter(project_id=project_id, exclude_from_ai=True).exists()

def _enqueue(ws_id, proj_id, stype, sid):
    key = f"reindex_pending:{stype}:{sid}"
    if cache.add(key, "1", timeout=10):          # дебаунс 10с
        reindex_source.apply_async(
            args=[str(ws_id), str(proj_id), stype, str(sid)], countdown=10)

@receiver(post_save, sender=Issue)
def issue_saved(sender, instance, **kwargs):
    if not _ai_enabled(instance.workspace_id) or _excluded(instance.project_id):
        return
    transaction.on_commit(
        lambda: _enqueue(instance.workspace_id, instance.project_id, "work_item", instance.id))

@receiver(post_delete, sender=Issue)
def issue_deleted(sender, instance, **kwargs):
    delete_chunks.delay("work_item", str(instance.id))
# аналогично IssueComment ("comment") и Page ("page")
```

Подключить сигналы в `ai/apps.py` (`ready()`).
