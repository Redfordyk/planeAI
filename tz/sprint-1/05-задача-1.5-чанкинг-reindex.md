## 🎯 Цель

Реализовать ядро ингеста: загрузка текста источника → чанкинг с перекрытием → эмбеддинг → запись в `DocumentChunk`. Идемпотентно (не переэмбеддивать неизменённое), устойчиво (retry), с учётом расхода токенов.

## 📋 Контекст для Claude Code

Это сердце RAG. Источники: задача (title+description), комментарий, страница (длинная — нужен чанкинг). Эмбеддер из 1.3 (`OpenAIEmbed.embed → (vectors, tokens)`). Учёт токенов пишется в `AIUsageLog` (полноценный record_usage — задача 1.7, здесь можно прямую запись embed-расхода).

## ✅ Что сделать

```python
# ai/chunking.py
import tiktoken
enc = tiktoken.get_encoding("cl100k_base")
MAX_CHUNK_TOKENS = 8000   # страховка под лимит эмбеддера

def chunk_text(text, target_tokens=400, overlap=50):
    assert target_tokens < MAX_CHUNK_TOKENS
    toks = enc.encode(text)
    if len(toks) <= target_tokens:
        return [(text, len(toks))]
    out, start = [], 0
    while start < len(toks):
        w = toks[start:start+target_tokens]
        out.append((enc.decode(w), len(w)))
        start += target_tokens - overlap
    return out

# ai/tasks.py
from celery import shared_task
from django.db import transaction
import hashlib
from decimal import Decimal

@shared_task(bind=True, max_retries=3, default_retry_delay=60)
def reindex_source(self, ws_id, proj_id, source_type, source_id):
    text = load_source_text(source_type, source_id)   # title+description / body
    if not text or not text.strip():
        return
    h = hashlib.sha256(text.encode()).hexdigest()
    existing = DocumentChunk.objects.filter(source_type=source_type, source_id=source_id)
    if existing.exists() and existing.first().content_hash == h:
        return  # идемпотентность
    chunks = chunk_text(text)
    cfg = WorkspaceAIConfig.objects.get(workspace_id=ws_id)
    try:
        vectors, tokens = OpenAIEmbed(cfg.openai_key, cfg.embed_model).embed(
            [c for c, _ in chunks])
    except Exception as exc:
        raise self.retry(exc=exc)
    with transaction.atomic():
        existing.delete()
        DocumentChunk.objects.bulk_create([
            DocumentChunk(workspace_id=ws_id, project_id=proj_id,
                          source_type=source_type, source_id=source_id,
                          chunk_index=i, content=c, token_count=t,
                          embedding=v, content_hash=h)
            for i, ((c, t), v) in enumerate(zip(chunks, vectors))])
        AIUsageLog.objects.create(workspace_id=ws_id, feature="embed",
            model=cfg.embed_model, input_tokens=tokens, output_tokens=0,
            cost_usd=Decimal(tokens) * Decimal("0.00000002"))

@shared_task
def delete_chunks(source_type, source_id):
    DocumentChunk.objects.filter(source_type=source_type, source_id=source_id).delete()
```

`load_source_text` — отдельная функция, маппящая source_type → реальные поля моделей (из SCHEMA.md).

## ✅ Definition of Done

- [ ] `chunk_text` режет длинный текст с перекрытием, короткий — один чанк
- [ ] `reindex_source` идемпотентна (повтор без изменений = no-op, проверено по content_hash)
- [ ] Эмбеддинг и запись в одной транзакции, старые чанки удаляются
- [ ] Расход токенов пишется в AIUsageLog
- [ ] Retry через Celery при сбое провайдера
- [ ] `load_source_text` использует реальные поля из SCHEMA.md
- [ ] Тесты: идемпотентность, чанкинг длинного текста, retry

## ⚠️ Важно

- Порядок: чанкуем ДО эмбеддинга, каждый чанк ≤400 токенов — не пробьёт лимит эмбеддера.
- Цена эмбеддинга `0.00000002` $/токен вынеси в общий `PRICING` (используется и в 1.7).
