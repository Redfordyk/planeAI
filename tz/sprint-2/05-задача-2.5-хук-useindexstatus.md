## 🎯 Цель

Хук + индикатор, показывающий статус индексации воркспейса. Чтобы не давать искать по пустому/неполному индексу и показывать прогресс бэкафилла.

## 📋 Контекст для Claude Code

Эндпоинт `1.8` отдаёт `{total_work_items, indexed, coverage, ready}`. Если `ready=false` — поиск стоит дизейблить или показывать предупреждение «индекс ещё наполняется (66%)». Без этого первое впечатление — «ИИ ничего не находит».

## ✅ Что сделать

```jsx
// useIndexStatus.js
import { useState, useEffect } from "react";

export function useIndexStatus(workspaceId, pollMs = 0) {
  const [data, setData] = useState(null);   // {total_work_items, indexed, coverage, ready}
  useEffect(() => {
    let timer;
    const load = () =>
      fetch(`/api/ai/${workspaceId}/index-status/`)
        .then(r => r.json()).then(setData).catch(() => {});
    load();
    if (pollMs) timer = setInterval(load, pollMs);  // опционально поллинг при бэкафилле
    return () => timer && clearInterval(timer);
  }, [workspaceId, pollMs]);
  return data;
}
```

Индикатор-компонент:
- если `ready` → ничего или зелёная галочка
- если не `ready` → «Индексация: {indexed}/{total} ({coverage*100}%)», прогресс-бар
- при `total === 0` → подсказка «нет задач для индексации»

## ✅ Definition of Done

- [ ] Хук тянет статус, опционально поллит при наполнении
- [ ] Индикатор показывает прогресс при `ready=false`
- [ ] Скрывается/зеленеет при `ready=true`
- [ ] Корректен при пустом воркспейсе
- [ ] Проверено против эндпоинта 1.8

## ⚠️ Важно

Поллинг включать только когда `ready=false` (идёт бэкафилл), иначе лишние запросы. Когда `ready=true` — остановить.
