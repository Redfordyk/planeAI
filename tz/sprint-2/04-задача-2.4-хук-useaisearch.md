## 🎯 Цель

React-хук, потребляющий SSE-поток от эндпоинта поиска: парсит кадры `sources` / `delta` / `error` / `done`, накапливает ответ, отдаёт состояние компоненту.

## 📋 Контекст для Claude Code

Контракт SSE (из 2.3): сервер шлёт кадры `data: {...}\n\n`. Порядок: сначала `{sources:[...]}`, потом много `{delta:"текст"}`, в конце `{done:true}`. Ошибки — `{error:"..."}`. Ошибки ДО стрима (бюджет 429 / AI off 403) приходят как обычный HTTP-статус, не как SSE.

## ✅ Что сделать

```jsx
// useAISearch.js
import { useState, useCallback } from "react";

export function useAISearch(workspaceId) {
  const [answer, setAnswer] = useState("");
  const [sources, setSources] = useState([]);
  const [status, setStatus] = useState("idle");   // idle|streaming|done|error
  const [error, setError] = useState(null);

  const search = useCallback(async (query) => {
    setAnswer(""); setSources([]); setError(null); setStatus("streaming");
    const resp = await fetch(`/api/ai/${workspaceId}/search/stream/`, {
      method: "POST", headers: {"Content-Type":"application/json"},
      body: JSON.stringify({ query }),
    });
    if (!resp.ok) {                                  // 429 бюджет / 403 off
      const b = await resp.json().catch(() => ({}));
      setError(b.error || `Ошибка ${resp.status}`); setStatus("error"); return;
    }
    const reader = resp.body.getReader();
    const dec = new TextDecoder();
    let buf = "";
    while (true) {
      const { value, done } = await reader.read();
      if (done) break;
      buf += dec.decode(value, { stream: true });
      const frames = buf.split("\n\n");
      buf = frames.pop();                            // хвост — недочитанный кадр
      for (const f of frames) {
        if (!f.startsWith("data: ")) continue;
        const d = JSON.parse(f.slice(6));
        if (d.sources) setSources(d.sources);
        else if (d.delta) setAnswer((p) => p + d.delta);
        else if (d.error) { setError(d.error); setStatus("error"); return; }
        else if (d.done) setStatus("done");
      }
    }
    // обработать остаток буфера (последний кадр без trailing \n\n)
    if (buf.startsWith("data: ")) {
      try { const d = JSON.parse(buf.slice(6)); if (d.done) setStatus("done"); } catch {}
    }
  }, [workspaceId]);

  return { answer, sources, status, error, search };
}
```

## ✅ Definition of Done

- [ ] Хук парсит кадры sources/delta/error/done корректно
- [ ] Ответ накапливается из дельт (печатается по мере прихода)
- [ ] HTTP-ошибки (429/403) обрабатываются отдельно от SSE-ошибок
- [ ] Обработан остаток буфера (последний кадр не теряется)
- [ ] Состояния idle/streaming/done/error переключаются верно
- [ ] Проверено против реального эндпоинта 2.3

## ⚠️ Важно (грабли из отладки)

1. `frames.pop()` сохраняет недочитанный хвост — НЕ убирай, иначе кадры рвутся на границе чанков.
2. Остаток `buf` после цикла нужно обработать — иначе последний `done` может потеряться.
3. `sources` приходят первым кадром — компонент (2.6) рисует ссылки сразу, до текста.
