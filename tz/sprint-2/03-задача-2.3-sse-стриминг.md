## 🎯 Цель

Эндпоинт, стримящий ответ Claude по SSE: первым кадром — источники, далее текстовые дельты по мере генерации, в конце — `done`. С корректной обработкой ошибок провайдера.

## 📋 Контекст для Claude Code — ⚠️ РАЗВИЛКА ASGI/WSGI

**Сначала открой `STREAMING.md` (задача 0.3).** Реализация зависит от режима:

### Если ASGI (uvicorn/daphne):
- async-генератор + `AsyncAnthropic` + `async with .messages.stream()` + `async for text in stream.text_stream`
- ЛЮБОЙ ORM-вызов из генератора (включая `record_usage`) — ТОЛЬКО через `sync_to_async`, иначе `SynchronousOnlyOperation`
- retrieval (ORM) — синхронная функция, обёрнутая в `sync_to_async`, ДО старта стрима

```python
# ai/streaming.py (ASGI-вариант)
import anthropic, json
from asgiref.sync import sync_to_async
from ai.usage import record_usage

async def claude_sse(cfg, system, messages, model, ws_id, user_id, feature, sources):
    yield f"data: {json.dumps({'sources': sources})}\n\n"   # источники ПЕРВЫМ кадром
    client = anthropic.AsyncAnthropic(api_key=cfg.anthropic_key)
    try:
        async with client.messages.stream(model=model, max_tokens=2048,
                system=system, messages=messages, temperature=0.1) as stream:
            async for text in stream.text_stream:
                yield f"data: {json.dumps({'delta': text})}\n\n"
            final = await stream.get_final_message()
    except anthropic.AuthenticationError:
        yield f"data: {json.dumps({'error':'Неверный ключ Claude'})}\n\n"; return
    except anthropic.RateLimitError:
        yield f"data: {json.dumps({'error':'Лимит запросов, попробуйте позже'})}\n\n"; return
    except anthropic.APIError:
        yield f"data: {json.dumps({'error':'Ошибка ИИ-провайдера'})}\n\n"; return
    await sync_to_async(record_usage)(ws_id, user_id, feature, model, final.usage)
    yield f"data: {json.dumps({'done': True})}\n\n"
```

### Если WSGI (gunicorn):
- синхронный генератор, `anthropic.Anthropic` + `with .messages.stream()` + `for text in stream.text_stream`
- `record_usage` вызывается напрямую (sync) — проблем с ORM нет
- помни: WSGI-воркер блокируется на время стрима

## ✅ Что сделать (общее для обоих)

1. Вьюха собирает контекст (retrieve из 2.1) синхронно (или через sync_to_async при ASGI), затем запускает стрим.
2. `StreamingHttpResponse(gen, content_type="text/event-stream")`.
3. Заголовки: `Cache-Control: no-cache`, **`X-Accel-Buffering: no`** (иначе nginx буферизует и стрим не идёт).
4. Декоратор `@require_ai_budget` (1.7) — 429/403 ДО старта стрима.
5. Источники — первым кадром (фронт в 2.4 их ждёт как `data.sources`).
