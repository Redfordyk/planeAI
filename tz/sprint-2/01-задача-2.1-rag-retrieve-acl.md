## 🎯 Цель

Реализовать retrieval-часть RAG: по тексту запроса найти релевантные чанки через векторный поиск pgvector, **строго отфильтрованные по правам пользователя**. Это половина киллер-фичи (вторая — синтез ответа в 2.3).

## 📋 Контекст для Claude Code

Принцип №1 и №2 из общего контекста: изоляция воркспейсов + ACL в коде. `allowed_project_ids` приходит из `allowed_projects()` (ACL.md, задача 0.6), а НЕ из запроса пользователя — иначе IDOR через границы воркспейсов. Эмбеддинг запроса — через `OpenAIEmbed` (1.3), который возвращает `(vectors, tokens)`.

## ✅ Что сделать

```python
# ai/search.py
from pgvector.django import CosineDistance
from ai.acl import allowed_projects
from ai.providers import OpenAIEmbed

def retrieve(workspace_id, user, query, cfg, top_k=20):
    # 1. эмбеддинг запроса (распаковка кортежа!)
    qvecs, _ = OpenAIEmbed(cfg.openai_key, cfg.embed_model).embed([query])
    qvec = qvecs[0]

    # 2. права — из ACL, НЕ из запроса
    allowed = allowed_projects(user, workspace_id)
    if not allowed:
        return []

    # 3. векторный поиск, ОБЯЗАТЕЛЬНО с фильтром workspace + allowed projects
    chunks = list(DocumentChunk.objects
        .filter(workspace_id=workspace_id, project_id__in=allowed)
        .order_by(CosineDistance("embedding", qvec))[:top_k])
    return chunks

def build_context(chunks) -> str:
    return "\n\n".join(f"[{c.source_type}:{c.source_id}] {c.content}" for c in chunks)
```

Доп:
- Опционально гибрид: подмешать полнотекстовый поиск Postgres по тем же фильтрам (повышает recall на точных терминах/ID). Для MVP — можно отложить, отметить TODO.
- Вернуть и список `source_id` чанков (для отображения источников на фронте).

## ✅ Definition of Done

- [ ] `retrieve` возвращает top-K чанков по косинусной близости
- [ ] Фильтр по `workspace_id` + `allowed_projects` присутствует ВСЕГДА
- [ ] `allowed_projects` берётся из ACL, не из параметров запроса
- [ ] Пустой список прав → пустой результат (не падение)
- [ ] Распаковка `qvecs, _ = embed(...)` корректна
- [ ] Тест изоляции: запрос из A не возвращает чанки B (переиспользует conftest из 1.9)

## ⚠️ Важно

Это место утечки данных между воркспейсами. Фильтр по правам — НЕ опция. Тест изоляции обязателен и должен быть в критическом наборе CI.
