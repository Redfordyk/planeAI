# План-график: все 12 фаз

> Полный путь от пустого сервера до автономной системы. Две части по ~неделям, каждая самоценна.

## Временная шкала (≈16 недель)

```
Часть I — Базовая версия (W1–W7):
  Ф0 фундамент    ▓ W1
  Ф1 бэкенд ИИ    ▓ W1-2
  Ф2 поиск        ▓ W2-3
  Ф3 генерация    ▓ W3
  Ф4 bulk         ▓ W4
  Ф5 агенты прост ▓ W4-5
  Ф6 прод/релиз   ▓ W6-7   ← РЕЛИЗ базовой ✅

Часть II — Агентская система (W7–W16):
  Ф7  PLANNER     ▒ W7-9
  Ф8  MONITOR     ▒ W9-11
  Ф9  EXEC+ESCAL  ▒ W11-13
  Ф10 ANALYST+COM ▒ W13
  Ф11 ORCHESTRATOR▒ W14
  Ф12 UI+приёмка  ▒ W15-16  ← РЕЛИЗ агентской ✅
```

## Две точки ценности

- **После Ф6:** рабочий продукт (поиск, генерация, bulk, простые агенты). Можно остановиться — уже лучше обычного трекера.
- **После Ф12:** полная автономная система (ставишь цель → планирует, исполняет, мониторит, эскалирует).

## Критический путь (что блокирует всё)

1. **0.2 SCHEMA.md** — имена моделей Plane, первая задача
2. **0.3 ASGI/WSGI** — определяет стриминг
3. **0.6 ACL.md** — фундамент безопасности
4. **1.3 LLM-абстракция** — все вызовы моделей
5. **2.1 RAG** — поиск + генерация + агенты
6. **7.2 Decision Layer** — каждое действие агента
7. **8.1 Event Stream** — реактивность агентов (защита от петли!)
8. **11.2 Kill-switch** — последний барьер runaway

## Gates (приёмки)

- 0: артефакты готовы → код
- 2.9: демо поиска
- 4.6: bulk — порог перед агентами
- 5.8: простые агенты (безопасность)
- 6.7/6.8: GDPR + релиз базовой
- Ф7–11: каждый агент принят отдельно
- 12.2: релиз агентской версии

## Сквозные риски (честно)

- **Токены:** multi-agent дорогой, нужны Haiku + дебаунс + кэш, мониторить с дня 1
- **Сервер:** 8 ГБ впритык, для агентов нужно 16 ГБ (NLs-4)
- **Холодный старт:** первые недели эвристики, не ML
- **Темп:** Ф0 недооценивается; фронт (один Эдик) — узкое место

**75 задач · 12 фаз · ~16 недель** (базовые 7 спринтов + 6 агентских фаз)
