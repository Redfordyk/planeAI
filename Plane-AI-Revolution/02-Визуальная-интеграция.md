# Визуальная интеграция: ИИ-интерфейс неотличим от Plane

> **Главный принцип:** пользователь не должен понимать, где заканчивается Plane и начинается ИИ-слой. Никаких «приклеенных сбоку виджетов». Агенты и оркестратор выглядят как родные части платформы.

---

## Как это достигается технически

### Факт о Plane (проверено)
Plane использует:
- **Tailwind CSS** с общим конфигом `@plane/tailwind-config`
- **CSS-переменные** для всех цветов/тем (`packages/tailwind-config/variables.css`)
- Три темы: **light, dark, high-contrast**
- Primitive токены (палитра) + semantic токены (роли в UI)
- React 18 + React Router 7, монорепо (web/admin/space)

### Вывод для нас
**Мы НЕ вводим свои цвета, шрифты, отступы.** Мы потребляем CSS-переменные Plane. Тогда наш интерфейс:
- автоматически совпадает по цвету
- автоматически переключается между light/dark/high-contrast
- наследует шрифты и скругления
- меняется вместе с Plane при их обновлении дизайна

## Правило №1: только переменные Plane, никаких хардкодов

❌ **Нельзя** (своя палитра):
```jsx
<div style={{ background: '#11151f', color: '#5eead4' }}>AI</div>
```

✅ **Нужно** (переменные Plane):
```jsx
<div className="bg-custom-background-100 text-custom-text-100">AI</div>
```

Plane определяет семантические классы `bg-custom-background-100`, `text-custom-text-200`, `border-custom-border-200` и т.д. Они меняются с темой. Используем ТОЛЬКО их.

### Семантические роли Plane
```css
--color-background-100/90/80   /* фоны по глубине */
--color-text-100/200/300/400   /* текст по важности */
--color-border-100/200/300     /* границы */
--color-primary-100..900       /* акцент */
--color-success/warning/error  /* состояния */
```

Бирюза/жёлтый из демо-презентации — это была демо-эстетика. В продукте — палитра Plane.

---

## Правило №2: переиспользуем компоненты Plane

У Plane есть пакет `@plane/ui`. Кнопки, инпуты, модалки, дропдауны — берём оттуда.

❌ `<button className="my-ai-button">Спросить</button>`
✅ `import { Button } from "@plane/ui"; <Button variant="primary">Спросить</Button>`

Переиспользуем: `Button`, `Input`, `TextArea`, `Dialog`/`ModalCore`, `Dropdown`, `CustomMenu`, `Tooltip`, `Tag`, `Avatar`, `Loader`, `Toast`.

---

## Правило №3: ИИ живёт в структуре Plane, не поверх

Не плавающий виджет, а встроенные разделы:

```
HEADER: [Workspace ▾] ... [🔍 Поиск по смыслу] [👤]   ← кнопка в хедере
SIDEBAR:
  Home / Inbox
  ─────
  🎯 Goals     ← новый раздел (стиль Plane)
  🤖 AI        ← лента агента (стиль Plane)
  ─────
  Projects
```

Разделы Goals/AI оформлены как пункты Projects/Inbox — та же иконка-слот, шрифт, ховер, активный стейт.

## Точки взаимодействия

### 1. Поиск по смыслу
Модалка `Dialog` из `@plane/ui` — та же, что command palette (Cmd+K). Ссылки на задачи `[MOB-342]` — тем же компонентом упоминаний, что в комментариях Plane.

### 2. Кнопки генерации
Пункт в `CustomMenu` задачи — рядом с «Copy link», «Delete». Не кнопка сбоку, а пункт в меню «...».

### 3. Bulk-команда
Превью — `ModalCore` Plane со списком задач штатным списочным компонентом. Кнопки — `Button`.

### 4. Агент как пользователь
Агент — `Avatar` Plane с иконкой 🤖. В ленте активности задачи его действия — как действия любого участника, тот же формат «кто · что · когда».

```
👤 Костя изменил статус → In Progress    2h ago
🤖 AI Assistant добавил метку "bug"       1h ago   ← тот же формат
👤 Эдик оставил комментарий               30m ago
```

### 5. Цели и лента агента
Страницы из тех же layout-примитивов, что страницы проектов — заголовки, breadcrumbs, отступы, карточки.

---

## Правило №4: иконки и анимации Plane
- Иконки — `lucide-react` (как у Plane): `Sparkles`, `Bot`, `Zap`
- Спиннеры/скелетоны при стриминге — компоненты Plane
- Анимации — те же длительности и easing

## Правило №5: тёмная тема бесплатно
Раз используем переменные Plane — light/dark/high-contrast работают автоматически, без отдельного кода. Контрастность и a11y наследуются.

---

## Антипаттерны (чего НЕ делаем)
❌ Плавающий чат-виджет в углу (как Intercom)
❌ Своя цветовая схема
❌ Самописные кнопки/инпуты/модалки
❌ Свой шрифт, чужой набор иконок
❌ AI-страница, оторванная от layout

---

## Чек-лист нативности (для каждого ИИ-компонента)
- [ ] Только `bg-custom-*`/`text-custom-*`/`border-custom-*` (нет хардкода)
- [ ] Кнопки/модалки из `@plane/ui`
- [ ] Иконки из `lucide-react`
- [ ] Работает в light/dark/high-contrast без отдельного кода
- [ ] Встроен в навигацию, не плавает
- [ ] Ссылки на задачи — штатным компонентом
- [ ] Действия агента — в формате штатной активности
- [ ] **Скрин-тест:** незнакомый человек не отличит, где Plane, а где наш слой

Последний пункт — финальный критерий приёмки визуала.

---

## Техническое следствие
Наши React-компоненты:
1. Живут в `apps/web` Plane (или в пакете, импортируемом туда)
2. Импортируют `@plane/ui` и `@plane/tailwind-config`
3. Без единого хардкод-цвета
4. В тех же провайдерах темы, что Plane

Требует сборки в монорепо Plane (см. IMAGE.md 0.5, ONBOARDING.md 0.12).
