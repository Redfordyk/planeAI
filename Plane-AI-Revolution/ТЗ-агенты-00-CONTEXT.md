# Агентские фазы (7–12) — ТЗ для Claude Code

> Расширение базовых 7 спринтов. Превращает Plane из «трекера с ИИ» в автономную систему управления проектами. Каждая фаза — детальные промпты для Claude Code.

## Структура

| Фаза | Агент | Задачи |
|---|---|---|
| 7 | PLANNER (декомпозиция цели) | 7.1–7.5 |
| 8 | MONITOR (мониторинг + предсказание) | 8.1–8.3 |
| 9 | EXECUTOR + ESCALATOR | 9.x |
| 10 | ANALYST + COMMUNICATOR | 10.x |
| 11 | ORCHESTRATOR (координация) | 11.x |
| 12 | Визуальная интеграция UI | 12.x |

## Нерушимые принципы

1. Изоляция воркспейсов — агенты только в своём
2. ACL везде — агент = пользователь с ограниченными правами
3. Контент = недоверенный ввод (защита от инъекций)
4. **Decision Layer** — обратимое/мелкое сам; необратимое/дорогое/стратегическое → человек; удаление → НИКОГДА
5. Бюджет токенов — жёсткий лимит (multi-agent жрёт много)
6. Защита от петли — `_modified_by_agent`, не триггерит повторно
7. Защита от runaway — circuit breaker, kill-switch, лимит действий
8. Полный аудит — каждое действие в AgentAction с обоснованием
9. Валидация выхода модели — PLANNER может галлюцинировать
10. Поэтапное включение — каждый агент за флагом, по одному

## Стек (расширение базового)
- **LangGraph** — координация multi-agent
- **LightGBM** — предсказание задержек (не нейросеть)
- **Event Stream** — сигналы Plane → Celery (расширение 1.4)
- **Haiku** для рутины, **Sonnet** для сложного

## Реалистичные предупреждения
- **Токены:** без дебаунса и Haiku — десятки $/день. Мониторить с первого дня.
- **Сервер:** 8 ГБ впритык, для агентов нужно 16 ГБ (NLs-4).
- **Холодный старт:** первые недели эвристики вместо ML.
- **Включать по одному**, не всех сразу.

## Новые модели (фаза 7)
`ProjectGoal`, `AgentAction` (с reasoning + risk_level), `PredictedRisk`, `TeamVelocity`.

## Связь с базовой версией
Надстройка, не замена. Использует RAG (спринт 2), agent loop (спринт 4), простых агентов (спринт 5), учёт токенов (спринт 1), ACL (0.6), kill-switch (6.5). Сначала базовая версия, потом агенты поверх.
