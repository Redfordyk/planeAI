# planeAI — гайд для команды

> Привет! У тебя в Plane появились ИИ-фичи. Этот документ — что они делают и как ими пользоваться. Под 5 минут чтения.
>
> Если что-то не так или не работает — пиши в Slack `#planeai-feedback`.

---

## Что есть

### 🔍 Семантический поиск

Открой свой workspace в Plane → в правом верхнем углу появилась кнопка `AI Search` (или Ctrl/Cmd+K).

Спрашивай естественным языком:
- «Какие задачи у меня открыты по платежам?»
- «Что Вася делал на прошлой неделе?»
- «Есть ли блокеры на текущий релиз?»

Что внутри: ИИ пробегает по индексу всех твоих задач, комментариев и страниц workspace, находит топ-10 релевантных, и пишет ответ со ссылками на конкретные задачи. Ответ стримится по словам, не нужно ждать конца.

**Что важно знать:**
- Поиск видит только то, к чему у **тебя есть доступ**. Чужие приватные проекты — не вылезут.
- Ответы могут ошибаться (модель есть модель). Если важно — **сходи в задачу по ссылке** и проверь.
- Поиск не делает действий. Он только читает и отвечает.

### 📝 Авто-саммари (если уже выпущено)

В длинной дискуссии (20+ комментариев) — кнопка `Summarize`. Получишь 5-7 буллетов: ключевые решения, кто что предложил, открытые вопросы.

### ⚡ Bulk-операции (если уже выпущено)

В правом верхнем — `AI Bulk`. Скажи: «закрой все задачи Васи с меткой done-but-open». Модель построит план, **покажет тебе список до выполнения**, ты подтвердишь — изменения применятся. **Без твоего подтверждения ничего не изменится.**

### 🤖 ИИ-агент (если активирован для твоего проекта)

Если в твоём проекте включён агент — назначь его на задачу (он будет в списке assignees как обычный пользователь). Через минуту он может:
- предложить приоритет / метки (как комментарий, не сам поставит);
- найти возможные дубли (комментарий со ссылкой);
- написать черновик описания (если описание пустое).

**Чего агент НЕ делает:**
- ❌ Не закрывает задачи.
- ❌ Не назначает их на людей сам (только предлагает в комментарии).
- ❌ Не редактирует существующее описание (только добавляет черновик в пустое).

Все его действия видны в `/<workspace>/settings/ai-agent`. Любое действие типа «поставил метку» можно **отменить** одной кнопкой.

Если агент мешает — выключи его в `<workspace>/settings/ai-agent` (toggle off). Это безопасно, ничего не сломает.

## Куда уходят мои данные

Текст твоих задач/комментариев/страниц уходит в:
- **OpenAI** (США) — для вычисления эмбеддингов (поиск).
- **Anthropic** (США) — для генерации ответа поиска / саммари / триажа.

DPA с обоими провайдерами подписан, zero-retention включён. Подробности: [GDPR-RELEASE.md](../GDPR-RELEASE.md) и [docs/processing-register.md](processing-register.md).

**Не клади в задачи** пароли, токены, личные данные коллег (паспорта, медданные). Если задача sensitive — попроси Илью пометить весь проект как `exclude_from_ai`.

## Что мне НЕ нравится / нашёл баг

Один из трёх каналов:
1. **`#planeai-feedback`** в Slack — для общих наблюдений, идей, мелких баг.
2. **`#planeai-bugs`** — для конкретных багов (скриншот + URL задачи + что ожидал).
3. **Напрямую Илье** — если что-то деликатное (про data, про privacy).

Каждый отзыв читается. Не каждый превращается в фичу за неделю — это нормально.

## Сколько это стоит

Расход видит админ workspace в `/<workspace>/settings/ai-usage`. Бюджет — 5M токенов/месяц на воркспейс по умолчанию (~$20-30 при типичном использовании). При достижении лимита — фичи временно отключаются до начала следующего месяца.

Если у твоей команды реально не хватает — пиши Илье, поднимем лимит.

## Где что в UI

| Что | Путь |
|---|---|
| Поиск | Кнопка `AI Search` (правый верх) или `Ctrl/Cmd+K` |
| Саммари | Внутри обсуждения задачи — кнопка `Summarize` |
| Bulk | `AI Bulk` (правый верх) |
| Дашборд расхода (admin) | `/<workspace>/settings/ai-usage` |
| Лента действий агента | `/<workspace>/settings/ai-agent` |
| Toggle агента (admin) | `/<workspace>/settings/ai-agent` → toggle |

## Я не хочу пользоваться ИИ совсем

OK. Тогда:
- Просто не используй фичи `AI *`. Plane сам по себе работает как раньше.
- Если хочешь, чтобы **твои задачи** не попадали в индекс — попроси Илью пометить твой проект как `exclude_from_ai`. После этого все существующие чанки этого проекта удаляются автоматически (см. [GDPR-RELEASE.md](../GDPR-RELEASE.md) пункт 4).
- Если хочешь полностью **выключить ИИ для всего workspace** — снова Илья (он сделает `disable_ai --workspace <id>`).
