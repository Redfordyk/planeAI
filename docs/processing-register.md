## 2. Категории обрабатываемых данных

| Категория | Источник в Plane | Содержит ли PII? | Чувствительность |
|---|---|---|---|
| Названия задач (`Issue.name`) | `db.Issue.name` | возможно (если автор вписал имя/email) | medium |
| Описания задач (`Issue.description_stripped`) | `db.Issue` | возможно | medium |
| Комментарии (`IssueComment.comment_stripped`) | `db.IssueComment` | возможно | medium |
| Вики-страницы (`Page.description_stripped`) | `db.Page` | возможно | medium |
| Email пользователя (косвенно — как автора) | `db.User.email` | **да** (только косвенно — если пользователь упомянул email коллеги в тексте задачи) | high |
| Содержимое прикреплённых файлов | `db.FileAsset` | возможно | **out-of-scope** — НЕ обрабатывается |
| Личные сообщения / DM | n/a в Plane CE | n/a | n/a |

**Принцип минимизации (GDPR Art. 5(1)(c)):** отправляется только текстовое содержимое перечисленных полей. Метаданные (assignee, project, дата) — не отправляются как часть промпта. Email авторов — не отправляется. Все вложения — не отправляются.

## 3. Получатели данных (трансферы)

| Получатель | Местонахождение | Что передаём | Зачем | Правовая основа |
|---|---|---|---|---|
| OpenAI L.L.C. | США | Текст задач / комментариев / страниц (≤4k токенов на чанк) | Эмбеддинг (`text-embedding-3-small`, 1536 dim) для семантического поиска | GDPR Art. 6(1)(f) + SCC + DPA + zero-retention |
| Anthropic PBC | США | Запрос пользователя + найденный контекст (top-K чанков, ≤200k токенов) | Генерация ответа RAG, авто-саммари, триаж | GDPR Art. 6(1)(f) + SCC + DPA + no-training |
| MinIO (внутри инсталляции) | EU, Франкфурт | AI-артефакты (черновики, draft-описания) | Хранение генерированного контента | внутреннее, не трансфер |

**Технические/организационные меры:**
- TLS 1.2+ in transit (оба провайдера).
- Encryption at rest на стороне провайдеров (декларировано в их security overview).
- Encryption at rest на нашей стороне: `WorkspaceAIConfig.anthropic_key` / `openai_key` через `django-encrypted-model-fields` (Fernet), ключ — `FIELD_ENCRYPTION_KEY` env var, хранится отдельно от БД-бэкапов.
- Per-workspace opt-in: `WorkspaceAIConfig.enabled=True` обязательно.
- Per-project opt-out: `AIProjectSettings.exclude_from_ai=True` блокирует индексацию.
- Sub-processor DPA: обе компании подписали наш DPA (см. [GDPR-RELEASE.md → пункт 1](../GDPR-RELEASE.md)).

## 5. Сроки хранения (retention)

| Где хранится | Что | Срок | Условия удаления |
|---|---|---|---|
| `ai_document_chunk` (pgvector) | Эмбеддинги задач/комментов/страниц + исходный текст чанка | **на время существования источника** | удаляется при soft/hard delete исходного объекта в Plane (signal handler в [`ai/signals.py`](../ai/signals.py)) |
| `ai_usage_log` | Кто / когда / сколько токенов / стоимость каждого LLM-вызова | **2 года** (для биллинга и аудита) | TTL job (TZ-TBD на спринт 7); сейчас вручную |
| `ai_agent_action_log` | Что агент сделал на каждой задаче (append-only) | **2 года** | то же |
| `ai_workspace_config` | API-ключи воркспейса (шифрованные) | пока существует воркспейс | удаляется при удалении воркспейса (`on_delete=CASCADE`) |
| Бэкапы pg_dump в S3-совместимом хранилище | Снимок всех таблиц | **90 дней** (см. BACKUP.md) | автоматический prune через `mc rm --older-than` |
| Контент у OpenAI / Anthropic | Запросы и ответы | **0 дней** (zero-retention) или **30 дней** (default OpenAI) | согласно DPA + zero-retention запросу |

**Проверка соблюдения retention:**
```bash
# AIUsageLog старше 2 лет (должно быть пусто после внедрения TTL):
docker compose exec -e PGPASSWORD=$POSTGRES_PASSWORD plane-db \
  psql -U plane -d plane -c "
    SELECT COUNT(*) FROM ai_usage_log
    WHERE created_at < (now() - interval '2 years');"
```

## 6. Права субъектов данных

| Право | Реализация в planeAI |
|---|---|
| Право на доступ (Art. 15) | Дашборд расхода `/<ws>/settings/ai-usage` (admin); запрос через PM для не-админов |
| Право на исправление (Art. 16) | Не применимо к эмбеддингам (производный продукт); исправление исходной задачи → автоматический re-embedding |
| Право на удаление (Art. 17) | Удаление задачи → signal удаляет чанки (`delete_chunks` task). Регрессионные тесты: [`test_gdpr.py`](../ai/tests/test_gdpr.py) |
| Право на ограничение обработки (Art. 18) | `WorkspaceAIConfig.enabled=False` (один воркспейс) или `AIProjectSettings.exclude_from_ai=True` (один проект) |
| Право на переносимость (Art. 20) | Через стандартный экспорт Plane (наши данные `ai_*` — производные, не подлежат экспорту) |
| Право на возражение (Art. 21) | opt-out через PM (см. выше) |
| Право не быть субъектом авто-решения (Art. 22) | ИИ-агент **не** принимает финальных решений: только комментарии и обратимые метки. Все действия идут через UI-подтверждение или возможность undo (TZ 5.6) |
