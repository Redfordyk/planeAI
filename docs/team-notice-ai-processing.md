**Привет, команда,**

С `YYYY-MM-DD` мы запускаем ИИ-фичи в нашем Plane. Перед этим — короткая прозрачная справка, потому что часть содержимого ваших задач будет уходить во внешние сервисы.

## Что мы запускаем

- **Семантический поиск.** Спрашиваешь «что у нас открыто по платежам?» — получаешь связный ответ со ссылками на реальные задачи. (TZ 2.x)
- **Авто-саммари длинных дискуссий.** (TZ 3.2, если уже выпущено)
- **Bulk-операции через естественный язык.** «Закрыть все задачи с меткой X» — модель делает план, ты подтверждаешь, изменения применяются. (TZ 4.x, если уже выпущено)
- **ИИ-агент.** На задачи, которые ты ему назначил, бот может предложить приоритет, метки, найти дубли, написать черновик описания. Никаких автоматических действий «сам решил и сделал» — это всегда комментарий или метка, обратимая через UI. (TZ 5.x, если уже выпущено)

## Какие данные уходят и куда

| Что | Куда | Зачем |
|---|---|---|
| Заголовок и описание твоих задач | **OpenAI** (US) | Вычисление эмбеддингов для поиска |
| Текст твоих комментариев | OpenAI | То же |
| Содержимое вики-страниц | OpenAI | То же |
| Твой поисковый запрос + найденный контекст | **Anthropic** (US) | Сгенерировать ответ на поиск |
| Текст задачи + промпт | Anthropic | Саммари, триаж, bulk-классификация |

**Что НЕ уходит:**
- Пароли, токены, любые секреты (мы их и так не храним в полях задач).
- Файловые вложения (attachments).
- Личные сообщения / DM в Plane.

## Что мы сделали для защиты

1. **DPA подписан** с обоими провайдерами (`YYYY-MM-DD`). По условиям API:
   - OpenAI и Anthropic **не используют** API-данные для обучения моделей.
   - Zero-retention запрошен и подтверждён там, где доступно.
2. **Проекты с конфиденциальной информацией исключены.** Из индексации убраны: `<список — HR, юристы, финансы и т.п.>`. Если ты ведёшь sensitive-проект и его нет в списке — напиши Илье, добавим.
3. **Удаление работает.** Удалил задачу / комментарий / страницу в Plane → её эмбеддинг автоматически уходит из ИИ-индекса в течение нескольких минут.
4. **Бюджет ограничен.** Месячный лимит токенов на воркспейс — расходы не разгоняются неконтролируемо.
5. **Логирование каждого вызова.** Кто, когда, сколько токенов, по какой фиче. Видно админам через дашборд `/<workspace>/settings/ai-usage`.

## Чего просим от тебя

- **Не клади PII (паспорта, личные контакты, медицинские данные) в задачи.** Текст задач = индексируется. Если PII действительно нужен — заведи sensitive-проект, мы его исключим.
- **Если хочешь полностью opt-out** для всего воркспейса — пиши Илье, выключим (`WorkspaceAIConfig.enabled=False`).
- **Если нашёл странное поведение ИИ** — пиши в Slack `#planeai-bugs`. Скриншот + ссылка на задачу.

## Твои права (GDPR)

- **Право на доступ.** Что именно отправлялось от твоего пользователя — видно в дашборде расхода (фильтр по user).
- **Право на удаление.** Удаление задачи в Plane = удаление её эмбеддингов. Если нужно гарантированное удаление профиля целиком (например, при увольнении) — пиши Илье.
- **Право на возражение.** Если ты против любой ИИ-обработки персонально — opt-out на уровне воркспейса (см. выше).
